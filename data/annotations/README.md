# Annotation artifacts and provenance

- `illustrative_reference_labels.json`: synthetic examples illustrating how positive/negative references may be represented. These are **not human-reviewed**.
- `benchmark_results.json`: generated by `python scripts/run_benchmark.py`; machine output over the development benchmark, not validated accuracy.
- Human annotation records are created at runtime in SQLite by the Human Review Workspace/API. The application never writes those records into the synthetic reference files.

The synthetic benchmark has development split metadata because it was used while implementing and tuning deterministic rules. Do not treat it as an independent holdout set.
